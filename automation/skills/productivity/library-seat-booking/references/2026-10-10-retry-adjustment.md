## 修改内容

### 1. 移除时间对齐逻辑（book-seat.sh）

**原逻辑：**
```bash
# ---- 绝对时间对齐 ----
WINDOW_AT="${BOOK_SEAT_WINDOW_AT:-19:18:30}"
_now=$(date +%s)
_target=$(date -d "today $WINDOW_AT" +%s)
_wait=$(( _target - _now ))
if [ "$_wait" -gt 0 ] && [ "$_wait" -lt 3600 ]; then
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] 对齐窗口：等待 ${_wait}s 至 $WINDOW_AT"
    sleep "$_wait"
else
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] 跳过对齐（wait=${_wait}s），立即执行"
fi
echo "[$(date '+%Y-%m-%d %H:%M:%S')] 开始登录，登录完成后立即抢座..."
```

**新逻辑：**
```bash
echo "[$(date '+%Y-%m-%d %H:%M:%S')] 开始抢座..."
```

直接启动，不再等待对齐窗口。

### 2. 重试次数改为100次（get_seat.py）

**原值：** 300次
**新值：** 100次

修改位置：
- 第153行：`while not flag and retries < 100:`
- 第312行：`if retries >= 100:`
- 注释中的"300次"改为"100次"

### 3. 效果评估

| 指标 | 原值 | 新值 |
|------|------|------|
| 最大重试次数 | 300 | 100 |

| 时间对齐 | 等待到19:18:30 | 立即启动 |

### 4. 注意事项

1. **重试预算有限**：脚本默认100次重试，自旋速度约10次/分钟。如果19:00就跑，20分钟的自旋会把所有重试次数耗在「未到预约时间」上。
2. **建议启动时间**：19:17左右启动，避免过早运行耗尽重试次数。
3. **Cron配置不变**：cron仍设置在19:17启动，实际运行时距19:20窗口开放约3分钟，重试预算足够。
