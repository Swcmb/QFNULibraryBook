# SPAC 规格与执行方案：课程论文生成（跳过个人信息与任务书）

## 1. 目的

基于 Course-Paper-Generator-Skill 流程，为 QFNULibraryBook 项目生成课程论文，跳过个人信息采集阶段和任务书生成阶段，仅输出课程论文文档。

## 2. 边界

### 范围内
- 阶段二已完成（项目深度分析通过用户确认）
- 阶段四：内容交叉验证（正常执行）
- 阶段六：课程论文生成（正常执行，个人信息字段使用占位符 `[待填写]`）
- 阶段六点五：参考文献自动核对
- 阶段七：输出课程论文文档

### 范围外
- 阶段三：个人信息采集（跳过，不向用户询问姓名/学号/院系等信息）
- 阶段五：任务书生成（跳过，不生成任务书文档）

## 3. 技术方法

对 Course-Paper-Generator-Skill 的七阶段流程做如下调整：

| 阶段 | 操作 | 说明 |
|------|------|------|
| 阶段一：项目发现与分类 | ✅ 已完成 | QFNULibraryBook，Python+Flask 全栈项目 |
| 阶段二：深度项目分析 | ✅ 已完成 | 分析结果已向用户展示 |
| **阶段三：信息采集** | **❌ 跳过** | 不询问个人信息 |
| 阶段四：内容交叉验证 | ✅ 执行 | 验证版本号、外部服务、数据库配置、非功能需求 |
| **阶段五：生成任务书** | **❌ 跳过** | 不生成任务书 |
| 阶段六：生成课程论文 | ✅ 执行 | 个人信息字段使用 `[待填写]` 占位 |
| 阶段六点五：参考文献核对 | ✅ 执行 | 自动核对格式和引用 |
| 阶段七：输出文档 | ✅ 执行 | 仅输出课程论文文件 |

## 4. 具体行动步骤

1. **阶段四：内容交叉验证**
   - 验证版本号（从 requirements.txt 提取 Flask>=3.0 等）
   - 验证外部服务（ids.qfnu.edu.cn、libyy.qfnu.edu.cn、Telegram/钉钉 API）
   - 验证数据库配置（无数据库，确认无 DB 配置）
   - 验证非功能需求（运行时依赖、Docker 部署）
   - 标记 `[需人工验证]` 项

2. **阶段六：生成课程论文**
   - 参照 `assets/course_paper_template.md` 生成
   - 论文题目：基于 Python Flask 的曲阜师范大学图书馆座位预约系统设计与实现
   - 论文中所有个人信息字段使用 `[待填写]` 占位符
   - 技术内容全部基于实际源码
   - 包含 Mermaid 图表（架构图、E-R图、流程图等）
   - 纯段落式学术写作

3. **阶段六点五：参考文献自动核对**
   - 格式规范性校验
   - 字段完整性检查
   - 一致性验证
   - 生成核对报告

4. **阶段七：输出文档**
   - 生成课程论文文件：`课程论文_软件工程_[学号]_[姓名]_QFNULibraryBook.md`
   - 不生成任务书文件

## 5. 成功标准

- 课程论文内容完整、技术描述准确可追溯到源码
- 所有个人信息字段使用 `[待填写]` 占位符
- 无任务书文件生成
- Mermaid 图表基于实际代码结构绘制

## 6. 异常处理

| 异常 | 处理方式 |
|------|---------|
| 用户后续需要任务书 | 可单独生成，不纳入本次流程 |
| 用户需要填入个人信息 | 可在论文生成后手动替换 `[待填写]` 占位符 |
| 参考文献无法自动核对 | 标记 `[需人工核对]` 并在报告中说明 |
